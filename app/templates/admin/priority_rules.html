How priority rules work: When a ticket is created, rules are evaluated in order number order. Within each rule, condition groups are OR-ed — the rule fires if any group matches. Within a group, all conditions are AND-ed. The first matching rule sets the ticket priority. If no rule matches, priority defaults to Medium. Users never see or select priority — it is always set automatically.
